# Changelog

## 2.0.0

- Portable Windows executable with a bundled runtime/browser and system-tray monitoring.
- Dark glass interface, light/system modes, five accents, and motion controls.
- Real garage profiles, vehicle photo uploads, parts checklists, budgets, and purchase history.
- Official eBay Browse adapter, seller links, listing galleries, buying-option actions, and full source records.
- Encrypted connection settings, live Discord connection tests, optional phone mentions, and an integrated command bot.
- Per-monitor dated Excel reports and live Activity updates.
- Forty-eight part presets, sourced reference cutouts, new branding, and reorganized documentation.

## 1.0.0

Initial Part Scout release: responsive inventory dashboard, validated monitors and filters, bookmarks and notes, price history, shared per-monitor inventory, serialized scheduling, provider backoff, durable Discord alerts, command bot, configuration portability, legacy search conversion, Docker configuration, and automated checks.

The original car-part-monitor idea and adapter format are credited to Peter Soboyejo. Live provider and Discord verification require operator permissions and credentials; fixture and local API tests are included.
